# Packlog FPV · strona

Statyczna strona aplikacji Packlog FPV na GitHub Pages: polityka prywatności po polsku, angielsku i niemiecku.

- `privacy/pl/`, `privacy/en/`, `privacy/de/`: polityka w każdym języku (aplikacja otwiera wersję w swoim języku).
- `privacy/`: wybiera język przeglądarki.
- `assets/fonts/`: IBM Plex hostowany tutaj, bez Google Fonts (licencja: `assets/fonts/OFL.txt`).

Później tu trafią pliki dla Universal Links i App Links (`.well-known/`) oraz strona `/p/` dla osób bez aplikacji.
